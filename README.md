# ⚡ SSPC Web Tools

## 概要
ブラウザ上で動作するDiscordの荒ʖˋᒐツールです。  
Spam Tool（メッセージ送信機能）とToken Checker（トークンチェック機能）を搭載しています。

## セキュリティについて
本ツールは以下の特徴を持ちます：

- サーバーへのログ送信は一切行いません
- 個人情報の収集・送信はありません
- 入力されたトークンはローカル環境（ブラウザのメモリ上）で処理され、外部に送信されることはありません

動作に疑念がある場合は、ソースコードを直接ご確認ください。
